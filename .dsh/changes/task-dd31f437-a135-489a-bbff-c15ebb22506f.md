- [revision 14] 深度自检后的修复，逐条对应自检发现的问题。

一、功能正确性缺陷（会实际写坏或漏掉东西）：
1. 扁平技能的入口文件绕过了 frontmatter 校验。原判定是 `basename(target) === 'SKILL.md'`，而扁平技能的入口是 `<name>.md`，于是它的 name/description 被改坏后发现器会静默丢弃整个技能。改为判定入口文件本身（`target === entry.path`），目录包的 SKILL.md 与扁平技能唯一的那个文件都覆盖，非入口文件仍不受限。补了一条回归用例。
2. 编辑草稿用空串表示「未编辑」，导致读者把文件清空后无法保存（`dirty` 判 false、保存按钮禁用）。草稿状态改为 `string | null`，`null` 才是未编辑，空串是可保存的显式编辑。
3. 导入目标根列出了全部可写根，包括不属于任何页签的 `custom` 根——从那里导入的技能在列表里根本看不到。改为只列出当前作用域内的可写根，并据此决定导入入口是否可用。补了一条回归用例。
4. 改导入来源或目标根后旧预览仍可提交：预览是按旧来源/旧根解析的，提交却会按新选择写入。两处 onChange 现在都清除预览。
5. 高亮层与 textarea 都开了 `overflow: auto`，编辑器会出现两套滚动条。高亮层改为 `overflow: hidden`，滚动仍由 textarea 驱动。

二、呈现与可访问性缺陷：
6. `display: flex` 直接加在 `<td>` 上会让单元格脱离表格布局，状态列与操作列改为单元格内包一层 div。
7. 启用列同时有复选框和「已启用/已禁用」文字，与状态列的徽标重复且挤压列宽。启用列只留复选框（aria-label 保留动作语义），状态列保留禁用徽标。
8. 编辑器的可访问名原本是语法语言名（且无扩展名时为空串），改为显示的文件路径。

三、遗漏的需求面：

- [revision 16] 修复停用行丢失卡片边框的样式缺陷。

原因：两行布局里 `.rowDisabled` 只声明了 `opacity`，而 JSX 用三元表达式在 `.row` 与 `.rowDisabled` 之间二选一，于是停用行的 `display: flex`、`padding`、`border`、`border-radius` 随基础类一起被丢掉——点开关后那一行看起来像掉出了列表。

两侧都修：
- CSS 把卡片框改为 `.row, .rowDisabled` 共享，`.rowDisabled` 只保留 `opacity`，与页面上其他条件类名（页签的 `.tab`/`.tabActive`、描述的 `.descriptionClamped`/`.descriptionFull`、文件树的 `.treeFile`/`.treeFileActive`）保持同一种结构。
- JSX 改为同时带上两个类（`${css.row} ${css.rowDisabled}`）而不是互相替换，这样即便将来 CSS 的共享规则被拆开，边框仍由 `row` 提供。

顺带排查了同类问题：页面上其余五处条件类名在 CSS 里都是共享基础样式的，只有这一处不是，所以没有其他同类缺陷。

防回归：新增用例断言停用行与启用行共享至少一个类名（即画边框的那个），且停用行多带一个类。修复前该断言为 0 个共享类，会失败。

- [revision 17] 导入预览改为与编辑技能同构的界面：左侧文件树，右侧带高亮的文件内容。
