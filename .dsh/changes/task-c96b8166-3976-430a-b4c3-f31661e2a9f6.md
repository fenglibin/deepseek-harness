- [revision 5] ## 改动

### `packages/client/ui-file-browser/src/client/CodeEditor.tsx`

预览开关的初值由 `useState(false)` 改为按扩展名惰性求值（`previewKindOfPath(path) !== undefined`），使可预览文件的首帧就是渲染结果；路径变化的 effect 同步改为「按新路径重取默认值」而非固定清零，并按 `path` 为依赖，使两个 Markdown 文件之间切换也会重取默认值。模块 JSDoc 同步说明这一默认。

### `packages/client/ui-file-browser/src/client/FileBrowserModal.tsx`

把 `openFile` 拆成 `readFile(path, keepOpen)`、`openFile`、`reloadFile`：修掉默认预览暴露出的一个真实回归——「重新加载」原先复用 `openFile`，会先把 `file` 清空，导致 `CodeEditor` 卸载重挂载、操作者被默认值拉回预览。重新加载现在保留当前文件，留在操作者所在的视图；打开另一个文件仍走清空路径。`onReload` 改传 `reloadFile`。
