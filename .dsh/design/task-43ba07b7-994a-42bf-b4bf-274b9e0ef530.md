- [revision 2] 决策 A：描述发生在 agent-loop 的 appendToolResult（append tool/result 之前，同步 await）。理由：模型可见 ⟺ 已记录，描述必须随 tool/result 同一次落盘；异步补描述需要 surfaceOp: replace 改写已落盘事件，会偏离下一请求前缀并作废 provider 前缀缓存。

决策 B：executeToolCalls 新增 inputModalities 参数，step 循环传入 preparedCall.inputModalities（请求正在派发的精确模态）。声明缺失 = 未知而非纯文本，routeExcludesImages(undefined) 为 false，不描述，投影行为与从前一致。

决策 C：dsh-llm 新增两个递归辅助函数（与 replaceImagesForTextModel 同一递归形态）：collectImageRefs(content) 按出现顺序收集图片引用；attachImageDescriptions(content, descriptions) 按序把描述挂到 image 块，不 mutate 持久化块。

决策 D：agent-loop 直接值导入 describeForRoute（image-understanding 的 consumer），image-understanding 加入 agent-loop 的 peerDependencies + devDependencies（照 dsh-llm 先例）。降级语义完全复用 describeForRoute：无 describer、图片路由、调用失败都退化为无描述，image 块保持原样。

决策 E：sessionId = session.id 传入 describeForRoute，使理解调用与主请求绑定到同一 recorded session（llm-replay 归属）。

非目标：subagent/ACP 直接构建 user/message 块的图片（不经网关也不经工具结果落盘点）仍是 gap，记录在 image-understanding README 的 Known Limitations，不在本任务范围。
