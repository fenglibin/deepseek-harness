- [revision 2] ## 设计：MCP 页面的"增加 MCP"与 JSON 化"编辑"

### 目标
1. 在"配置MCP"按钮左侧新增"增加MCP"按钮，弹 JSON 编辑器贴入 MCP 配置，支持同名覆盖确认与 `mcpServers` 包裹剥离，写入 mcp.json。
2. 将每个 MCP 服务的"编辑"从表单对话框改为 JSON 编辑器，展示单服务配置，保存回写 mcp.json，与增加流程视觉统一。

### 关键决策

**D1 纯前端实现，复用现有 `writeMcpDocument` RPC。**
Host 的 `writeMcpDocument(text)` 已是"完整校验(parseMcpJson + mcpJsonToSettings) + 持久化 + 立即同步"路径。增加/编辑只需在前端合并或替换 mcp.json 中的单条服务器后，把整份文本交回 `writeMcpDocument`，无需新增 Host RPC。后端校验仍兜底拒绝非法条目，错误经 `McpDocumentStore.error` 回显。

**D2 单服务 JSON 用跨厂商 `McpJsonServer` 形状，而非 `McpServerEntry`。**
编辑器的文本是用户可读的 mcp.json 形状：`{"command":…,"args":[…],"env":{…}}` 或 `{"url":…,"headers":{…}}`。`enabled` 映射为 `disabled`（`enabled=false → disabled:true`），与 parseMcpJson 的 `disabled !== true` 取反语义一致。serverName/transport 不进 JSON（serverName 由点击的行确定，transport 由 command/url 存在性判别）。

**D3 新增纯函数模块 `mcp-server-json.ts`（无 React、无 ctx），承载所有 JSON 形状转换。**
职责：
- `parsePastedServers(text)`：解析贴入文本 → 剥离 `mcpServers` 包裹 → 返回 `{ name: McpJsonServer 对象 }` 的 map（保留原始字段，供合并）。
- `entryToServerJson(entry)`：`McpServerEntry` → 单服务 McpJsonServer JSON 文本（用于编辑初始展示）。
- `mergeServerText(currentText, servers)`：把新 map 合并进当前 mcp.json 文本（同名覆盖）。
- `replaceServerText(currentText, name, serverJson)`：替换单条。
- `extractServerNames(text)`：从贴入文本解析服务器名列表（用于同名检测）。

**D4 同名覆盖确认在"增加"保存路径的前端完成。**
保存贴入配置前，用 `extractServerNames` 与现有 `state.servers` 比对；有交集则弹 Modal 确认，同意后合并写入（覆盖），拒绝则中止。确认框复用 `Modal` 原语，文案走 locale。

**D5 复用 `McpJsonEditor`，通过新增可选 prop 定制标题/初始文本。**
`McpJsonEditor` 增加 `title?: string`（默认 `editorTitle`）。增加流程用空初始文本 + 标题"增加 MCP 服务器"；编辑流程用 `entryToServerJson(entry)` 文本 + 标题"编辑 {server}"；配置流程保持整份 mcp.json 不变。

**D6 移除表单式 `McpServerDialog`。**
增加与编辑统一为 JSON 编辑器后，`McpServerDialog.tsx` 及其 module.css 不再被引用，删除。`McpStore.update(entry)`（结构化表单写）被"替换文本写"取代，`McpStore` 保留 toggle/remove，新增 `upsertFromText` 语义改由 `McpDocumentStore` 承载（见 D1）。

### 数据流
- 增加：贴入 JSON → parsePastedServers → 同名检测 → (确认覆盖) → mergeServerText(当前 doc.text) → document.write。
- 编辑：entryToServerJson(entry) → 用户编辑 → replaceServerText(doc.text, name, 新对象) → document.write。
- 配置：保持现有整份 mcp.json 读写不变。

### 边界
- 贴入文本既无 `mcpServers` 也非 `{name: 对象}` map（例如裸 `{"command":"…"}`）→ 报错提示需包含服务器名（locale `addNeedsName`）。
- 编辑保存时 JSON 语法错误由编辑器 in-place 拦截；结构/字段错误由 Host `writeMcpDocument` 拒绝并回显。
- 只读部署下"增加/编辑"按钮随 `state.writable` 禁用，与现有 toggle/remove 一致。
