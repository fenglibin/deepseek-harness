- [revision 3] 在「增加MCP」与「编辑」弹框中加入配置说明与帮助入口。三项设计决策：(1) 分层呈现——弹框顶部用一行简短提示（editorHint）说明最常用路径并指向帮助，完整参考放在独立的帮助弹窗；理由是本页已有较高编辑器，熟悉格式的用户不应每次滚过文档。(2) 帮助弹窗（McpHelp.tsx）承载三节：基础配置（stdio 与 streamable-http 各一个可粘贴示例）、OAuth 服务器（字段示例 + 授权步骤）、可选字段（allowedTools/env/headers/cwd 示例），末尾说明 mcp.json 与设置页两种入口等价；两种传输共用一个「基础配置」标题、以 label 区分（stdio（本地进程）/ streamable-http（远程端点）），避免同名标题重复出现。(3) 全部文案与四个 JSON 示例都放在 settings.mcp locale 字典中，不是组件内字面量——仓库的 verify-client-ui-i18n 门禁要求产品可见文案归 locale 所有，示例文本也是产品可见内容。实现：McpJsonEditor 增加 helpOpen 状态与标题下的「帮助」链接按钮（置于编辑器上方而非 footer，footer 属于保存/取消决策），帮助弹窗作为 Portal 独立于编辑器弹窗，关闭它不影响编辑器草稿；新增 McpHelp.tsx 与 McpHelp.module.css（dialog 宽度 760px、仅 body 滚动、pre 保留缩进以便直接粘贴）。
