- [revision 3] 设计草案写入 docs/design/mcp-oauth-config-reachability.zh.md。根因：设计阶段的 D6「mcp.json 对 OAuth 只读不写」是错的——设置页的编辑功能建立在 mcp.json 往返之上，写入方向省略 OAuth 字段导致编辑器看不到它们、保存时丢失。仓库里 allowedTools 已给出正确先例（同为 dsh 扩展字段但读写对称，其他平台按未知字段忽略）。三项决策：D7 OAuth 字段读写对称，仅 auth.kind === 'oauth' 时写出，none 条目输出逐字不变，scopes 仅在携带时写出；D8 读方向的「沉默继承」从缓解措施改述为升级与手编兼容（旧版本 mcp.json 无 OAuth 字段时首次手编仍会丢配置，且半配置情形仍报错而非静默降级）；D9 本次不新增表单控件，只修数据丢失与可发现性，独立 OAuth 表单作为后续增强。验证计划覆盖编辑往返、mcp.json 往返、none 条目零变化、手编可配置、以及设置页保存后 Host 侧 auth 仍为 oauth 的端到端断言。
