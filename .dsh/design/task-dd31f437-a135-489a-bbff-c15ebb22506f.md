- [revision 3] 完整设计写在 docs/design/skill-settings-ux.zh.md，要点如下。

作用域映射（D1）：三个子 TAB 在客户端按根 source 映射——全局=user-agents（~/.agents/skills）、应用=user-dsh（~/.dsh/skills）、工作区=project-dsh+project-agents；custom 与 bundled 不进入任何 TAB。映射留在客户端，因为 source 已是发现器的稳定契约，归屏是呈现决策。

启用/禁用（D2-D4）：用同根的 `.disabled/` 子目录承载——禁用把 `<root>/<name>/` 或 `<root>/<name>.md` 整体移入，启用移回。发现器只扫根的一层直接子项，因此禁用即刻从模型目录与用户命令目录消失；rename 原子且技能文件零改动；移动触发 watcher 的原路径 unlinkDir 与新路径 addDir，缓存失效无需额外通道。否决了目录内标记文件（扁平技能无法对等表达）、frontmatter 新键（键随文件复制传播，语义脱离部署）、DSH 配置清单（状态脱离技能本体）。发现器补一条显式跳过，把"禁用目录永不被发现"从巧合变成契约。管理面额外扫描 `.disabled/`，把条目标为 `enabled: false` 并留在表格里，否则用户没有恢复入口。

文件编辑（D5-D6）：新增 listFiles/readFile/writeFile 三个 Remote 方法，不复用只服务 frontmatter 表单的 read。每次解析后的路径必须落在条目目录内；文件数与深度设上限；单文件超限或含 NUL 字节判为只读；写入 SKILL.md 前校验 frontmatter 合法，因为发现器会静默丢弃不合法条目。编辑区是透明 textarea 叠加 shiki 高亮层，复用 ui-primitives 的 highlightLines，语言提示直接取扩展名（LANG_ALIASES 的键即扩展名），textarea 用 wrap=off 保证两层行对齐，不引入编辑器依赖。

导入（D7）：上传与 URL 共用同一套解包校验——把 import/source.ts 的「下载」与「解包内存字节」拆开，上传字节经规范 base64 承载后交给同一段解包，预览承诺的文件清单就是落盘清单。

页面结构（D8）：列表页只做展示，顶部一行放作用域 TAB、工作区选择器（仅工作区 TAB）与「导入技能」按钮，中部是名称/描述/状态/启用/编辑/删除的表格，写入都进弹窗；新建表单从页面移除，create 保留在 Remote 面上。
