- [revision 3] 完整设计见 `docs/design/skill-management-plugin.zh.md`。要点：

**包结构**（新建一对 + 改动一个）
- 新建 `packages/host/skill-manager`（`@deepseek-ai/dsh-host-skill-manager`）：Remote 命名空间 `skillAdmin`，承载 list/read/create/update/remove/previewImport/commitImport。
- 新建 `packages/client/ui-settings-skills`（`@deepseek-ai/dsh-client-ui-settings-skills`）：注册 `settings.section`（id `skills`，order 17）。
- 改动 `packages/skill/skill-filesystem`：新增只读服务 `ctx.skillRoots`，暴露当前生效的根（path/source/rank/projectRoot/readOnly）。

**关键决策**
- D1 新增独立 `skillAdmin` 命名空间，不扩展会话寻址的只读 `skills`。
- D2 管理视图扫描文件系统真相（含被遮蔽项、非法项与绝对路径），不走注册表合并视图。
- D3 根定义由 `dsh-skill-filesystem` 暴露，管理插件不重新推导，避免写入发现器不扫描的目录。
- D4 项目根由客户端从 `useWorkspaces` 显式传入，未提供时只呈现全局根，不猜测 cwd。
- D5 文件操作走 Node fs + `@deepseek-ai/dsh-util-atomic-write`，不经 `ctx.fs`（后者缺删除与建目录能力，混用会产生两套沙箱语义）。
- D6 写入后的模型侧可见性依赖 Chokidar 监视器；界面写入成功后自行重读清单，不等待监视器。
- D7 frontmatter 局部编辑保注释与键序，调用开关写显式布尔值。
- D8 导入分两阶段：`previewImport` 解包到内存不落盘，`commitImport` 按预览标识落盘。
- D9 解包硬校验：拒绝路径穿越、绝对路径、符号链接/硬链接、非常规文件、超限体积与文件数、tar 的 PAX/GNU 长名扩展；以 `fflate` 解压 zip 与 gzip，tar 结构按受控子集自解析。
- D10 删除需二次确认并报告确切路径；`bundled` 与未声明可写的 `custom` 根只读；`user-agents` 提示与其他 agent 共享。

**明确不做**：技能正文内容审查与风险标记（按已确认需求由用户在预览环节自行判断）。
