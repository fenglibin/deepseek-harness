# 为什么

设置 → 插件 页面的「全局插件」分组已经能在页面上启停插件，「会话插件」分组还没有：那一组的开关被限制在用户自建预设上，而实际部署里全是随部署自带的 `system` 预设，所以一个开关都看不到——功能等于没有交付。

同时那一枚开关在启用状态用 `--dsw-alias-brand-primary` 做底色，这个别名在浅色外观下是近黑的 `neutral-bluish-1000`，在浅色界面上就是一块黑色药丸，与「已启用」的语义也不相干。

插件卡片展开后只有一句 frontmatter 描述。每个插件包自己都写了完整的 `README.zh.md`，里面是它真正的用法、配置与边界，但页面上没有任何入口能看到。

# 改什么

- 「会话插件」每一行都能启停，随部署自带的预设同样可写；写入落在它自己的组合文件里，并且是保注释的局部编辑。
- 开关的启用底色换成随外观变化的语义色。
- 展开的描述末尾增加「查看更多」，点击后以模态弹窗渲染该插件 `README.zh.md` 的全文，支持表格、代码高亮、数学公式、图片与 mermaid 流程图。
- README 全文按需惰性读取，不进入清单快照。

# 不做什么

- 不新增插件、不改动清单快照的分组与搜索语义。
- 删除预设仍然只对用户自建预设开放。
- 不为 README 弹窗新写一套 Markdown 渲染器。
