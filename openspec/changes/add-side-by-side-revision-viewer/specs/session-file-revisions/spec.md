## ADDED Requirements

### Requirement: 变更在独立的全屏视图中展示

界面 SHALL 把「查看变更」的 diff 呈现在一个独立的全屏覆盖层中，MUST NOT 把它渲染在输入条带内。

#### Scenario: 点击查看变更打开全屏视图

- **WHEN** 用户点击某文件的「查看变更」
- **THEN** 界面打开一个全屏对话框展示该文件的变更，且输入条带内不出现 diff

#### Scenario: 以 dialog 语义暴露并可关闭

- **WHEN** 全屏视图已打开
- **THEN** 它以带标题的 dialog 暴露，并可由关闭控件、Escape 或点击遮罩退出

### Requirement: 变更以并排方式对照展示

界面 SHALL 把一次改动展示为左右两栏，左侧为会话开始前的内容、右侧为会话结束后的内容，且两栏按行对齐。

#### Scenario: 替换占用同一行

- **WHEN** 文件中某一行被改写为另一行
- **THEN** 被改写的那一行与其新内容出现在同一行上，左右两栏各自标出自身版本

#### Scenario: 单侧增删以空占位对齐

- **WHEN** 某一行只在一侧存在
- **THEN** 另一侧在同一行渲染为空占位，两栏的行号与内容保持对齐

#### Scenario: 两栏各有自己的行号

- **WHEN** 视图展示一份变更
- **THEN** 每一侧显示其自身版本的行号，空占位侧不显示行号

### Requirement: 变更视图提供 git 风格的阅读辅助

界面 SHALL 为并排视图提供语法高亮、变更行背景、行内字符级差异标注，以及变更之间的跳转。

#### Scenario: 按文件语言高亮

- **WHEN** 被查看文件的扩展名对应一个已知语言
- **THEN** 两栏内容按该语言着色，未知扩展名退化为等宽纯文本且不报错

#### Scenario: 标出替换行内部真正改动的字符

- **WHEN** 一行的两侧都被渲染且内容相近
- **THEN** 该行内部发生变化的字符被单独标出

#### Scenario: 在变更之间跳转

- **WHEN** 文件含多处变更而用户触发上一处或下一处
- **THEN** 视图移动到相邻的变更区段并显示当前位置与总数

### Requirement: 复制产出标准 diff

界面 SHALL 让复制产出统一格式（`-`/`+`）的 diff 文本，MUST NOT 复制并排布局本身。

#### Scenario: 复制内容可被 diff 工具接受

- **WHEN** 用户在全屏视图中触发复制
- **THEN** 剪贴板收到的是统一格式 diff 文本，而不是两栏排列的文本

### Requirement: 不可预览的情形如实说明

界面 SHALL 在无法给出 diff 时说明原因，MUST NOT 画出图省事的替代内容。

#### Scenario: 内容超过预览上限

- **WHEN** 宿主以 `oversized` 表示不下发正文
- **THEN** 视图说明文件过大无法预览，且不绘制任何 diff 行

#### Scenario: 基线未捕获

- **WHEN** 宿主以 `baseline-missing` 表示会话覆写前的内容未捕获
- **THEN** 视图说明无法预览也无法撤销，且不把末态画成整文件新增

#### Scenario: 读取被拒绝

- **WHEN** 宿主拒绝读取该文件的差异
- **THEN** 视图报出该失败，且不渲染任何内容栏

### Requirement: 查看变更的能力仍按记录逐行判定

界面 SHALL 只为宿主确实记录了修订的路径提供「查看变更」，MUST NOT 为没有记录的路径显示该入口。

#### Scenario: 没有修订记录的文件行

- **WHEN** 某文件出现在变更列表中，但该会话没有它的修订记录
- **THEN** 该行不显示「查看变更」，其余行不受影响

#### Scenario: 会话进行中新增的文件

- **WHEN** 某文件在视图挂载之后被 agent 改动，且宿主为其记录了修订
- **THEN** 该行无需刷新页面即可获得「查看变更」
