# 技术决策

完整草案见 `docs/design/revision-side-by-side-diff.zh.md`；此处记录决策要点。

### D1 触发与承载分离

dock 只发布请求，`shell.overlay` 承载渲染，两者经 `apply` 闭包内的一个共享 observable 连接。dock 在 session 作用域内、查看器在 root 作用域上，这个 observable——而不是组件树——是请求跨过该边界的通道。与 `ui-file-browser` 同构（其请求源见 `src/client/index.ts:131-145`，覆盖层注册见 `:205-215`）。

### D2 覆盖层形态

复用 `Modal` 的 `headless` 模式，由本包 CSS 给出与文件浏览器一致的框架尺寸（`min(1180px, 94vw)` / `min(820px, 92vh)`）。选 headless 是因为 diff 需要自有的头部布局（文件名、路径、+/- 统计、复制、关闭同排），默认的标题/描述/关闭三件套容不下。Esc、遮罩点击、关闭按钮三条退出由 `Modal` 提供。

### D3 并排对齐是独立的投影，不是渲染选择

把 hunk 行序列折叠成 `[left, right]` 行对：相邻连续 `-` 行与连续 `+` 行按索引配对，第 i 删与第 i 增占同一行；一侧多出的补 `null` 并渲染为空占位。因此两栏始终等高、行号对齐。上下文行两侧相同。行号分别由 hunk 的 `oldStart`/`newStart` 递增，空位侧不编号。

`\ No newline at end of file` 标记必须跳过：它是补丁的注解而不是文件的一行，画出来会显示文件里没有的文本并让其后所有行号错位。

### D4 默认全文件展开，只折叠超长文件

与 `DiffBlock` 的 16 行折叠不同：全屏空间已充足，折叠会再次制造「看不到全貌」的问题。仅当超过 `MAX_VISIBLE_ROWS`（2000 行）时折叠中部并保留展开控件——这是为超大文件兜底的必要约束，不是可选优化。

### D5 高亮复用既有 shiki 单例，并消除重复的语言映射

两侧都用 `highlightLines`。语法未加载时先渲染纯文本、加载完成后经 `subscribeGrammarLoaded` 重渲染；未知扩展名退化为纯文本，绝不报错。

语言映射原本在 `tool-fs` 与 `ui-file-browser` 各有一份完整拷贝。本变更把它收归高亮器的所有者 `ui-primitives`（`src/file-language.ts`），并让 `ui-file-browser` 改为再导出——避免加上第三份必须永远一致的表。归属依据：该表决定向哪个语法模块取词法，因此必须与单例同处；它是表现事实，因此属于 Client。

行内字符级高亮对配对成功且两侧都存在的行用 `diffChars` 标注增删片段；单行超过 `MAX_INLINE_DIFF_CHARS`（2000 字符）时跳过内部标注，只保留整行背景——字符差异在极端情况下是二次复杂度，压缩产物的一行可能有数百 KB。

### D6 两栏只同步横向滚动，纵向由外层独担

两栏各自 `overflow-x: auto`，横向滚动同步（用一次性标志加下一帧释放来打断回声，否则两侧会互相触发）。纵向滚动由正文区统一承担——两栏各自纵向滚动会让行错位，而这是对照视图唯一不能犯的错。

### D7 变更导航

底部条提供上一处/下一处跳转（在变更区段间移动并滚动到位）与「第 N / 共 M 处」读数，并支持 J / K 键。变更区段由连续变更行构成，因此一处多行替换只算一个目标。这是 git difftool 最有用的导航能力。

### D8 复制输出统一格式

复制的是 `-`/`+` 标准 diff 文本而非屏幕上的两栏布局：落到终端、issue 或 patch 文件里的东西必须是这些工具接受的 diff，而两栏转写不是。已与用户确认选统一格式。

### D9 查看器是只读评审面

查看器不提供撤销动作。撤销是破坏性的且作用于整个会话记录，留在能看到全部文件的 dock 上，避免同一操作有两个所有者与两套进度状态。这条同时消掉了一处实现重复：撤销的生命周期只有一份。

### D10 既有能力保留

`DiffBlock` 不删除、不改语义，继续服务会话内的工具调用卡片（`ui-tool` 的 `ToolRow` 是其消费者）。`withheld` 三态、失败文案与错误码分派原样复用。

## 验证

- 对齐模型（本变更唯一的真实逻辑）用 21 个单测锁定边界：替换配对成同一行、纯增、纯删、不等长区段、新建文件（`before: null`）、空文件、单行、有/无尾换行、跨 hunk 行号连续、变更区段划分、字符级区间、超长行跳过、统一格式输出。
- 查看器 15 个用例覆盖：以 dialog 打开、两栏栏目名、同行配对、两侧行号、+/- 统计、字符级标记、跳转与读数、跳转回绕、复制内容为 ` a\n-b\n+B`、oversized/baseline-missing/empty/失败四种状态、关闭、文件名与路径分离。
- dock 13 个用例覆盖：能力缺席、按行门控、发布请求而非内联渲染、会话进行中新增文件、撤销四态与重取。
