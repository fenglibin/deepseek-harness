# @deepseek-ai/dsh-client-ui-file-browser

## 概述

本包把两个贡献挂进 Web GUI：一个工作区行「...」菜单里的**文件浏览器**条目，以及一个挂在 `shell.overlay` 上的文件管理器弹层。弹层左侧是工作区目录的懒加载树（含文件名搜索、新建、重命名、删除），右侧是选中文件的内容区。文本文件进编辑器，带按扩展名解析的 shiki 语法着色，可编辑并保存；图片用 `<img>` 查看；二进制与超过大小上限的文件给出明确提示而不进编辑器。所有磁盘操作都经由 Host 的 `fileBrowser` Remote（[`dsh-api-file-browser`](../../api/file-browser/README.zh.md)）。

<a id="use-this-package"></a>
## 使用本包

把本插件与 `dsh-api-file-browser`、`ui-workspace` 一起挂载即可。它出现在组合里之后，每个真实工作区行的菜单就多出**文件浏览器**一项；Ungrouped 分桶没有菜单，因此也没有该条目。

### 弹层的两列

左列是工作区根目录的树。每个目录在**首次展开时**才列举一层，折叠不会丢弃已取回的层，所以重新展开是即时的。默认隐藏点开头的条目与 `node_modules`、`.git`、`dist` 等重目录，面板上的**显示隐藏项**开关会重新从根目录开始取。列举在 Host 的条数上限处截断时会明确说明。左列顶部还有按文件名搜索：输入片段后树被一份扁平结果列表取代，点击结果会展开其祖先目录并打开该文件。搜索只匹配名称，不匹配内容。

右列由文件读取回来的分支决定：文本进编辑器，图片用 `<img>` 呈现，二进制与超限文件各给出自己的提示，读取失败另有一行提示。

### 编辑器

编辑器是上层透明 `<textarea>` 叠在下层只读高亮层之上，两层共用字体、行高与内边距，所以光标落在字上。着色按扩展名解析语言，覆盖常见的后端与前端语言以及 JSON、YAML/YML、XML、TOML、INI、HTML、CSS、Markdown；无法识别的扩展名回退为纯文本，仍可编辑保存。着色器是 `ui-primitives` 里那个唯一的 shiki 单例，颜色取自 `--shiki-*` 主题变量。

`Ctrl+S`（macOS 为 `Cmd+S`）保存，工具栏上也有保存按钮；缓冲区与磁盘内容不一致时显示未保存标记。保存携带读入时的版本令牌，磁盘上的文件若已被其它程序改动，保存会以冲突被拒绝，并给出**重新加载**与**强制覆盖**两个选择——前者重新读取磁盘内容，后者不带版本令牌写入。

### 树上的文件操作

面板头部提供新建文件与新建文件夹（落在当前选中项所在目录，没有选中则落在根目录）。每个条目悬停时有重命名与删除；新名称必须是单个非空路径片段。删除先经过一次确认，文案指明目标名称并说明该操作不可恢复，取消则什么都不会发生。

### 卸载

菜单条目、弹层注册与 Host 侧的 Remote 贡献都随插件 fiber 生命周期生效。销毁本插件会一并移除它们，不留可点击的死入口。

<a id="model-experience"></a>
## 模型体验

无，因为这是运维人员直接操作文件的管理界面：它不注册提示词、工具或会话事件，也不改变任何模型请求。

#### KV Cache 影响

无直接影响；通过该界面查看或编辑文件不会改变模型请求。

## 已知限制与延期工作

<a id="known-limitations-and-deferred-work"></a>

- 编辑器提供语法着色，但不提供自动缩进、括号匹配与多光标：它是 textarea 叠加高亮层，不是完整的代码编辑器。
- 语言只由扩展名决定，界面上没有语言选择器。
- 没有文件监视，磁盘上的外部改动不会自动反映到已打开的文件；只有保存冲突与手动重新加载会让它进入视图。
- 一次只打开一个文件，没有多标签页。
- 树列的宽度固定，不可拖拽调整。
- 没有文件内容检索，也没有下载入口。

<a id="dev-note"></a>
### 开发备注

<details>
  <summary>维护者工作上下文——点击展开</summary>

`apply` 内的两次注册共享一个闭包持有的「打开请求」源：菜单项把被点击的工作区推入，弹层订阅它并渲染对话框。该状态既不需要跨重挂载存活（不入 store），也不能是模块级单例（`apply` 是唯一合法的创建点），因此放在闭包里。对话框是唯一持有服务端状态的地方——树渲染被交给它的层，编辑器渲染被交给它的缓冲区——所以新建、重命名、删除各自该刷新哪一层都只有一处实现。

</details>
